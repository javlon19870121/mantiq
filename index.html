Mantiqiy amallar nima?

Mantiqiy amallar faqat ikki xil qiymat bilan ishlaydi: ROST (1) va YOLG'ON (0).

  • VA (AND) — natija faqat ikkala qiymat ham ROST bo'lsagina ROST bo'ladi.
  • YOKI (OR) — natija kamida bitta qiymat ROST bo'lsa ROST bo'ladi.
  • EMAS (NOT) — qiymatni teskarisiga aylantiradi (1 ni 0 ga, 0 ni 1 ga).
  • XOR — qiymatlar bir-biridan farq qilsa ROST, bir xil bo'lsa YOLG'ON bo'ladi.

Supabase'ni sozlash bo'yicha yo'riqnoma

  1. Loyiha ochish: supabase.com saytiga kirib ro'yxatdan o'tasiz va "New Project" tugmasi orqali yangi loyiha yaratasiz.
  2. Jadval yaratish: Chap menyudan SQL Editor bo'limini oching va shu faylning yuqori qismidagi (kod ichidagi izohlarda berilgan) SQL buyrug'ini to'liq nusxalab, "Run" tugmasini bosing.
  3. URL va kalitni olish: Chap menyudan Project Settings → API bo'limiga kiring. U yerda Project URL va anon public kalitni topasiz. Ularni shu faylning SUPABASE_URL va SUPABASE_ANON_KEY o'zgaruvchilariga joylashtiring.
  4. "row-level security policy" xatosi chiqsa: Bu RLS (Row Level Security) siyosati to'g'ri yozilmaganini bildiradi. SQL Editor'da quyidagi tekshiruvlarni qiling:
    • Jadvalda RLS yoqilganiga ishonch hosil qiling (enable row level security).
    • insert va select uchun anon roliga policy yaratilganini tekshiring (pastdagi SQL'da bor).
    • Agar policy nomi takrorlansa, avval drop policy bilan eskisini o'chirib qayta yarating.
